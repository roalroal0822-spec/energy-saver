# 에너지 절감 비서 (공공건물 에너지 점검)

2026 공공 AI 대전환 챌린지 세션1 · AI 정부 실험실 챔피언십(자유주제) 출품작

공공기관이 운영하는 청사·체육센터·문화회관·주차장 같은 건물의 전기·가스 고지서와 사용 내역을 넣으면, **기온 영향을 걸러 낸 뒤에도 많이 쓴 달**, 휴관 중 설비 미정지, 실제보다 크게 잡힌 계약전력, 역률요금, 고지 금액 오류를 찾아 근거와 금액을 붙여 알려 주고, 담당 부서에 보낼 점검 요청서와 월간 보고서를 만들며, 조치를 시행한 뒤에는 절감 효과(kWh·원·tCO2eq)를 측정하는 도구입니다.

## 왜 필요한가

- 에너지 담당자는 매달 시설별 고지서를 받지만, 사용량이 늘었을 때 **날씨 탓인지 설비·운영 탓인지** 가려낼 도구가 없어 전년 같은 달과 단순 비교에 그칩니다. 더운 여름에는 늘어도 넘어가고, 정말 새는 곳은 묻힙니다.
- 계약전력·역률·요금 단가처럼 고지서 안에 숨은 비용은 전문 지식이 있어야 보입니다.
- 절감 조치를 해도 효과를 날씨 영향과 분리해 측정하지 못해, 다음 예산·투자 판단의 근거가 남지 않습니다.

## 접속 주소

실행하면 브라우저가 자동으로 열립니다. 열리지 않으면 **http://localhost:8104** 로 접속하세요.
(포트 변경: `python run.py --port 9000` 또는 `config.json`의 `port`)

## 실행 방법

필요한 것: Python 3.10 이상, 인터넷(처음 한 번 라이브러리 설치). 모델은 없어도 됩니다.

- **Windows**: `run.bat` 더블클릭 (처음 실행 때 실행 환경을 만들고 라이브러리를 설치한 뒤 시작)
- **macOS·Linux**: `./run.sh`
- **직접 실행**:
  ```
  pip install -r requirements.txt
  python run.py
  ```
- 종료: 실행 창에서 `Ctrl+C`

## 주요 기능

- **자료 넣기**: 엑셀 사용 내역(전력·가스), 시설 현황(면적·휴관 기간), 월평균기온, 조치 이력, 고지서 PDF, 기관 지침(한글)을 끌어다 놓으면 열 이름으로 알아서 읽습니다. 고지서 PDF는 항목 이름으로 읽고, 모델을 연결하면 형식이 다른 고지서도 읽되 **고지서 원문에 실제로 있는 숫자만** 받아들입니다.
- **기온 보정 진단**: 시설·에너지별로 기준 기간 12개월의 사용량을 `기저 + 냉방계수×냉방도일 + 난방계수×난방도일`로 맞춘 기준선을 만들고, 이후 달의 '기온만 감안한 예상 사용량'과 실제를 비교합니다. 기준선의 설명력(R²)과 오차율(CV-RMSE)을 함께 보여 줍니다.
- **점검 6종**: ① 기온 보정 후 초과 사용(전기) ② 가스 초과 사용(연소 설비) ③ 휴관 기간 설비 미정지 ④ 요금적용전력 과다 ⑤ 역률 미달 ⑥ 고지 전력량요금 재계산 차이. 결과마다 근거 행(파일·행 번호), 관련 지침 조문, 금액과 계산식, 확인할 일을 붙입니다.
- **점검 기준을 지침에서 읽기**: "10% 이상 많은", "50% 미만", "90% 미만" 같은 기준값을 넣은 기관 지침 조문에서 읽어 씁니다. 지침을 고쳐 다시 넣으면 점검 기준이 바뀝니다.
- **점검 요청서**: 점검 결과마다 담당 부서에 보낼 요청서(근거 자료·확인할 일·관련 기준)를 한글(HWPX)·워드·마크다운으로 만듭니다.
- **조치 등록과 효과 측정**: 점검 결과에서 조치를 등록하고, 완료 처리하면 시행 다음 달부터 기준선과 비교해 절감량·금액·온실가스를 자동으로 계산합니다(휴관 달 제외, 지침에 정한 기간 이상 쌓이면 '효과 확인').
- **물어보기**: "체육센터 8월 전기 왜 늘었어?", "주차장 기본요금 줄일 수 있어?"처럼 물으면 계산된 사실에서만 답하고 출처를 붙입니다.
- **감축 목표 진척**: 지침의 감축 목표 조문(예: "기준 기간보다 5% 이상 줄이는 것을 목표")에서 목표율을 읽고, 최근 12개월(휴관 달 제외) 실제 사용량을 기온 보정 기준선과 비교해 목표까지 남은 양과 시설별 기여를 보여 줍니다. 점검 결과의 초과 사용을 조치했다면 어디까지 갔을지도 같은 계산으로 보여 줍니다. 지침에 목표 조문이 없으면 표시하지 않습니다.
- **다음 달 시설별 관리 목표**: 기준선 모델에 작년 같은 달 월평균기온을 넣어 시설별 예상 사용량과 점검선(지침의 초과 기준)을 미리 알려 줍니다. 예보가 아니라 작년 기온을 쓴 값입니다.
- **엑셀 내보내기**: 점검 결과(근거 조문·계산식·출처), 시설별 월 내역(실제·기온 보정 예상·차이), 조치 효과를 시트별로 담은 xlsx를 만듭니다.
- **월간 보고서**: 총평, 시설별 현황(전년 대비·기온 보정 후), 점검 결과, 감축 목표 진척·다음 달 관리 목표, 조치 이행·효과, 점검 기준과 계산 방법을 한 문서로 만듭니다.

## 작동 방법 (시연 순서)

1. 실행하면 모의자료(2024.10.~2026.08. 엑셀 내역)를 자동으로 불러와 **한눈에 보기**가 열립니다.
2. **자료 넣기**에서 "시연: 9월 고지서 PDF 5장 넣기"를 누르면 PDF 고지서를 읽어 최신 달이 2026-09로 바뀝니다.
3. **점검 결과**에서 7건(조치 필요 5, 검토 2)의 근거·금액·계산식·관련 조문을 확인하고 "점검 요청서(한글)"를 내려받습니다.
4. **시설별 분석**에서 종합체육센터를 고르면 7·8월 막대가 점선(기온만 감안한 예상)을 크게 넘는 것이 보입니다.
5. **물어보기**에서 예시 질문을 누릅니다.
6. **절감 조치·효과**에서 문화예술회관 LED 교체의 기온 보정 효과(-8.2%)를 확인하고, 점검 결과에서 조치를 등록·완료 처리해 봅니다.
7. **보고서**에서 월간 보고서를 한글로 내려받습니다.

발표·영상용 대본은 [시연대본.md](시연대본.md)에 있습니다.

## 모델(LLM) 연결과 교체

- 모델 없이도 모든 기능이 규칙과 계산으로 동작합니다. 모델은 ① 형식이 다른 고지서 읽기 보조 ② 질문 답변·총평 문장 다듬기에만 씁니다. 진단·금액 계산은 모델이 하지 않습니다.
- 모델이 준 값과 문장은 대조를 거칩니다. 고지서 값은 원문에 그 숫자가 있어야 쓰고, 답변·총평에 계산된 사실에 없는 숫자가 하나라도 있으면 그 답을 버리고 규칙 답을 보여 줍니다(화면에 이유 표시).
- 화면 오른쪽 위 **모델 배지**를 누르거나 `config.json`(예시: `config.example.json`)에서 바꿉니다. OpenAI 호환 API(행정안전부 AI 공통기반, vLLM, Ollama `/v1` 등)와 Ollama 기본 API를 지원하고, 젬마·라마·GPT-OSS·엑사원·하이퍼클로바X·솔라 계열의 응답 차이를 자동 처리합니다.
- 모델 검증: `모델검증.bat`(Ollama로 젬마·엑사원) 또는 `python tools/verify_models.py --base-url <주소> --models <모델1> <모델2>` → `verify_report.md`. 모델 없이 연결 경로만 시험하려면 `--mock`.

## 설정값 (config.json의 energy)

| 항목 | 기본값 | 뜻 |
|---|---|---|
| cdd_base, hdd_base | 18 | 냉방·난방도일 기준온도(℃) |
| closure_expected_ratio | 0.35 | 휴관일에는 평소의 이 비율만 쓴다고 보고 휴관 달 예상치를 다시 잡음(가정값) |
| contract_margin | 0.2 | 계약전력 검토안 = 최고 최대수요전력 × (1 + 여유율) |
| co2_per_kwh | 0.4594 | 전력 온실가스 배출계수(kgCO2eq/kWh). 기관이 쓰는 고시값으로 바꿔 쓰세요 |
| tariff | 모의 단가 | 계절별 경부하·중간부하·최대부하 단가(원/kWh). 기관 계약종별 단가로 바꿔야 요금 재계산이 정확합니다. 고지서 절반 이상이 맞지 않으면 '단가 설정 확인'으로만 알립니다 |

## 원본 보호와 데이터 위치

- 넣은 파일은 읽기만 하고, 작업 폴더(`data/source`)에 사본을 둡니다. 조치 기록·작업 기록도 `data/`에만 저장합니다(설정 `data_dir` 또는 환경변수 `APP_DATA_DIR`).
- 화면은 이 PC에서만 열리며(127.0.0.1), 다른 웹사이트에서 보낸 요청은 거부합니다.

## 점검

- `python tests/smoke_test.py`: 서버를 임시 폴더로 띄워 자료 읽기·점검 결과·질문·보고서·조치·보안 경로를 차례로 호출합니다(24개 항목).
- `python tools/verify_models.py --mock`: 가짜 모델 서버 두 종류로 모델 연결 경로를 시험합니다. 하나는 일부러 지어낸 숫자를 넣으며, 앱이 그 답을 버리는지 확인합니다.

## 알려진 제약

- 도일은 월평균기온으로 근사합니다. 일별 기온이 있으면 더 정확해집니다. 기준 기간 자료가 6개월 미만이거나 기온 자료가 없으면 전년 같은 달과 비교합니다.
- 고지서 PDF는 시연용으로 만든 모의 고지서로만 시험했습니다. 실제 한국전력공사·도시가스사 고지서는 형식을 확인하지 못했고, 항목 이름이 다르면 모델 연결이 필요하거나 엑셀 내역으로 넣어야 합니다. 스캔 이미지 PDF는 읽지 못합니다.
- 요금적용전력 산정 방식, 역률요금 기준은 계약종별로 다르므로 계약전력·요금 관련 결과는 '검토' 대상이며 공급사 확인 후 확정해야 합니다.
- 금액은 고지서 단가와 설정값으로 계산한 추정치이고, 항목마다 기준(연간·월간·이미 낸 금액)이 달라 화면에 기준을 함께 적었습니다.
- 모의자료의 기관·시설·수치는 모두 지어낸 것입니다.
